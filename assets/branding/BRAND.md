# Caskly brand

**Mark:** the cocktail glass — ink-black glass, brand-purple drink, green
olive with pimento on a pick, on a soft white tile.

| File | Use |
|---|---|
| `caskly_icon_mac.svg` | macOS app icon (Big Sur grid: tile with margin + soft shadow) |
| `caskly_icon_win.svg` | Windows icon / installer, in-app logo above 48 px |
| `caskly_icon_small.svg` | 16–48 px: bold simplified glass (taskbar, sidebar) |
| `caskly_mark.svg` | glass only, transparent — on your own background |
| `caskly_app_icon_master.png` | 1024 px render of the macOS icon |

All four SVGs are generated by `tooling/brand/make_svgs.py` (edit there,
never by hand). `tooling/brand/install_icons.sh` regenerates them, renders
every size and installs the macOS iconset and Windows `.ico`.

**Colours**

| | Hex |
|---|---|
| Brand purple (drink, UI primary) | `#6C5CE7` |
| Purple light / deep | `#8E80F2` / `#3B2CA8` |
| Ink (glass) | `#16161F` |
| Tile | `#FFFFFF` → `#ECEAF3` |
| Olive / pimento | `#7E9B33` / `#C8402F` |

**Type:** Manrope (UI), JetBrains Mono (numbers).

Keep clear space of ¼ the icon width around the mark. Don't recolour the
glass, place the mark on busy photos, or stretch it.
