# Caskly brand

**Mark:** a flat, solid martini glass in cream on a matte ink tile. A single
cut of negative space across the bowl separates a thin rim from the drink.
Two colours only: no gradients, gloss, glow or garnish. That restraint is the
point; glossy and illustrated versions were tried and rejected.

| File | Use |
|---|---|
| `caskly_icon_mac.svg` | macOS app icon (Big Sur grid: tile with margin + soft shadow) |
| `caskly_icon_win.svg` | Windows icon / installer, in-app logo above 48 px |
| `caskly_icon_small.svg` | 16–48 px: heavier stem, foot and cut (taskbar, sidebar) |
| `caskly_mark.svg` | glass only in ink, transparent: for light backgrounds |
| `caskly_mark_light.svg` | glass only in cream, transparent: for dark backgrounds |
| `caskly_wordmark.svg` / `caskly_wordmark_light.svg` | stacked lockup (mark above spaced CASKLY), ink / cream; `make_wordmark.py` (needs fonttools) |
| `caskly_app_icon_master.png` | 1024 px render of the macOS icon |

All SVGs are generated by `tooling/brand/make_svgs.py` (edit there, never by
hand). `tooling/brand/install_icons.sh` regenerates them, renders every size
and installs the macOS iconset and Windows `.ico`.

**Colours**

| | Hex |
|---|---|
| Ink (tile, mark on light) | `#141218` |
| Cream (glass) | `#F3EFE6` |
| Brand purple (UI primary only, not in the mark) | `#6C5CE7` |

**Type:** Manrope (UI), JetBrains Mono (numbers).

Keep clear space of ¼ the icon width around the mark. Don't add colour,
gradients or effects to the glass, put the mark on busy photos, or stretch it.
